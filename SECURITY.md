# セキュリティ / Security

## 日本語

まだ公開リリースはなく、サポート対象のバージョンもありません。脆弱性を見つけた場合は、公開Issueを作らず、[GitHubの非公開脆弱性報告](https://github.com/kotaitos/codemorph/security/advisories/new)を利用してください。再現方法と影響を分かる範囲で記載してください。

解析対象の文書や秘密情報そのものを報告に添付しないでください。メンテナーが非公開で確認し、対応方針を返信します。

## English

There is no published release or supported version yet. To report a vulnerability, use [GitHub private vulnerability reporting](https://github.com/kotaitos/codemorph/security/advisories/new) rather than a public issue. Include reproduction steps and the impact if known.

Do not attach source documents or secrets. The maintainer will review the report privately and respond with next steps.
